Smart Appointment Scheduling Kiosk — Architecture

Barangay Dolores • Taytay, Rizal • 4-Tier Distributed System

Web Application (Vercel)

  • • 9 pages: /, /login, /register, /booking, /my-appointments
  • • /profile, /kiosk, /dolores-taytay-admin, /settings
  • • 5 SMS API routes under /api/sms/*
  • • Firebase Auth + RTDB (Web SDK)
  • • Stateless HMAC OTP (Node.js crypto)

Kiosk Host (RPi4)

  • • Python 3 + customtkinter touchscreen GUI
  • • 6 screens: Home, Verify, Result, Admin, Enroll, OTP
  • • 3 background threads (heartbeat, commands, appointments)
  • • Firebase Admin SDK (service account)
  • • pyserial → ESP32 at 115200 baud

Embedded Hardware

  • • ESP32 Dev Module + AS608 Optical Sensor
  • • 10 serial commands (PING, FP_ENROLL, FP_VERIFY, etc.)
  • • 500ms continuous monitor mode
  • • 127 fingerprint template slots max
  • • UART 57600 baud (ESP32 → AS608)
  • • SMS via Semaphore.co (PH gateway)
